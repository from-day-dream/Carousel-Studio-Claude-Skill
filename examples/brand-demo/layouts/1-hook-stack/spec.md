# Layout 1: Hook stack

**Best for:** hook, single idea     **Image:** none (grid paper)

## Grid & margins
- Outer margin: 96px (brand safe area 72px)
- Columns: 6; text block spans all 6 (888px). Key line max width 800px.
- Vertical anchor: headline starts ~378px from top on the hook, ~324px on body slides (with a kicker above it).

## Zones (x, y, w, h in px)
| Zone | Box | Notes |
|---|---|---|
| meta (handle / counter) | 96, 96, 888, 28 | handle left, `NN / 05` right |
| kicker | 96, 324, 888, 28 | body slides only ("Mistake 1", "Step 2") |
| headline | 96, 378, 888, ~420 | 3–4 lines at 132px (hook), 1–2 lines at 96px |
| key line | 96, +56 below headline, 800, ~120 | 2 lines max |
| support / fix panel | +72 below key | optional, one only |
| swipe cue | 96 → right edge, y ≈ 1188 | hook only: 2px line running off the edge, chevron |
| teaser line | 96, 1226, 888, 28 | meta style, points to the next slide |

## Type scale
- Headline : key line ≈ 3 : 1 on the hook (132/44), ≈ 2.2 : 1 on body slides (96/44).
- Emphasis: one word in Fraunces italic, accent colour.

## Image treatment
- None. Paper + 54px grid.
